3. JavaScript Validation Logic
The website uses JavaScript validation to ensure that users enter valid information before submitting the reservation form.

The validation checks include:
-	Full name cannot be empty
-	Email address must follow correct email format
-	Phone number must contain valid digits
-	Restaurant selection must be selected
-	Reservation date and time cannot be in the past
-	Number of people must be greater than zero
-	Deposit amount must be a valid positive number

If incorrect information is entered, an error message appears and the form is not submitted until the user fixes the input.
